Sobre Quiadsa Screen Sharing

Quiadsa Screen Sharing es una aplicación sencilla de compartición de pantalla que utiliza tecnología web moderna. Comparte tu pantalla directamente con otras personas en tiempo real, sin salir del navegador.

Conexión segura

Las conexiones directas de igual a igual (WebRTC) están cifradas de extremo a extremo.

Baja latencia

Transmisión en tiempo real optimizada para minimizar el retraso entre los participantes.

Configuración sencilla

Funciona directamente en tu navegador, sin plugins ni instalaciones necesarias.

Cómo funciona

Esta aplicación utiliza WebRTC para establecer conexiones de igual a igual directamente entre navegadores. La configuración inicial de la conexión (señalización) usa WebSockets para intercambiar la información necesaria. Una vez establecida la conexión WebRTC, el WebSocket normalmente ya no es necesario para los espectadores.

Compatibilidad con navegadores

La compartición de pantalla mediante WebRTC funciona en navegadores modernos como: Google Chrome, Mozilla Firefox, Microsoft Edge (basado en Chromium) y Apple Safari.

Sin embargo, la captura de audio junto con el vídeo de pantalla puede variar según el navegador y el sistema operativo:

  • Chrome / Edge: El mejor soporte en general, especialmente en Windows. En macOS o Linux, la captura de audio junto con la pantalla puede tener limitaciones.
  • Firefox: También ofrece buen soporte para la captura de pantalla y audio.
  • Safari: Admite la compartición de pantalla; la captura de audio simultánea puede ser menos consistente.

Recomendación: Para tener la mejor experiencia compartiendo tu pantalla con audio, utiliza la última versión de Google Chrome o Microsoft Edge. Concede siempre los permisos necesarios cuando se soliciten. La calidad depende de las capacidades del navegador y de las condiciones de red.

Nota: El rendimiento depende de las condiciones de red. Más información en WebRTC.org.
